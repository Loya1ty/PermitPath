# PermitPath

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

A prospective-customer demonstration for homeowners, builders/designers, and public-sector plan-review organizations. The working homeowner journey is brief, editable diagram, scoped checks, alternative strategies, and a locally exported review-preparation packet. Its purpose is reducing avoidable rework, not guaranteeing approval.

## Capabilities and constraints

Two synthetic projects: a residential deck and a bathroom remodel. Virginia/U.S. residential scope only; North America has no single building code. No implemented Canadian or Mexican coverage. Deterministic illustrative checks are not professional design, complete code review, or an authority having jurisdiction (AHJ) decision. Unknowns never count as satisfied checks.

Static, low-resource, GitHub Pages-compatible deployment. No backend, AI service, credentials, uploads, cloud storage, real billing, or permit submission. Local browser storage is optional and explicitly disclosed. All navigation resolves to working features or useful labeled previews.

## Confirmed brand commitments

PermitPath; navy #102A43, teal #007F7A, mint #B9E9DC, off-white #F6F8FA; original blueprint-like diagrams. Accessible operational product UI, not a marketing-only site.

## Evidence and commercial context

The supplied brief specifies hypothetical plans: Home $29/month, Pro $149/month, Team $499/month, and Agency from $18,000/year. No real customer, adoption, savings, approval, or deployment claims are available. Regulatory sources must be public authoritative references with visible review dates.

## Implementation assumptions

The user explicitly authorized proceeding without aesthetic questions. Fairfax County is the illustrative local jurisdiction, not a claim of support for every Virginia locality. Keyboard-accessible responsive web controls and a light working canvas serve users planning at a desktop or reviewing on a phone.
